# FED Assignment Project – SG Heart of Hawker

## Pages Implemented

### Menu Page
- Displays food offerings in a clear and structured card-based layout.
- Uses high-quality images to enhance visual appeal and user engagement.
- Allows users to search for dishes using keywords.
- Provides category filters to organise items by food type.
- Includes an add-to-cart function for ordering selected items.
- Designed with usability in mind to allow easy browsing of menu items.

### About Page
- Presents an overview of the platform’s purpose and mission.
- Communicates the goal of preserving Singapore’s hawker culture through digitalisation.
- Uses structured text and images to improve readability and engagement.
- Highlights the platform’s values and vision in a clear layout.
- Includes call-to-action buttons to guide user interaction.

### Contact Us Page
- Displays essential contact information in a clear and accessible format.
- Provides a contact form for users to submit enquiries or feedback.
- Ensures required input fields are completed before submission.
- Focuses on simplicity and ease of communication.
- 
- Maintains consistent navigation and responsive design.

## Technologies Used
- HTML and CSS for layout and styling.
- JavaScript for interactivity and DOM manipulation.
- Responsive design techniques for cross-device compatibility.
